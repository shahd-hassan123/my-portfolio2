# ✈️ Tripo – Travel & Vacation Booking Website

Tripo is a modern and responsive travel website designed to help users explore destinations, discover vacation trips, and plan their travel experience through a simple and user-friendly interface.

## ✨ Features

* Explore travel destinations
* Browse vacation trips
* View trip details
* Travel booking interface
* Responsive design
* Easy navigation
* Modern and attractive UI

## 🛠️ Technologies

* HTML
* CSS
* JavaScript
* Bootstrap

## 🎯 Project Purpose

The project was created to practice front-end web development and UI design while building a practical travel and vacation booking experience.
